# Block Brawl

An original fan-made 2.5D platform fighter for phone and desktop browsers. It is built with Three.js, and every model, texture, sound and music track is generated procedurally.

**Play:** https://bigbenny1231.github.io/block-brawl/

Controls: on a phone, use the left joystick and the A / B / Jump / Shield buttons. On a keyboard, use WASD or the arrow keys, J to attack, K for specials, Space to jump and L to shield.
